## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab
- pip package manager

### Installation

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install --upgrade pip
pip install jupyterlab
```

### Running the notebooks

```bash
jupyter lab
```

Then open the notebook files in the repository and run the cells as needed.
